# Harness Flight

A ~20 minute 3D talk: a Minecraft-style plane flies twelve waypoints covering the history of AI-in-the-editor, the Cursor Harness, and company-level time/quality math.

**Live:** https://bublikus.github.io/harness-flight/

```bash
npm install
npm run dev
```

- **Take off** starts the campaign (~95s per waypoint).
- **Space** skips ahead. **P** holds.
